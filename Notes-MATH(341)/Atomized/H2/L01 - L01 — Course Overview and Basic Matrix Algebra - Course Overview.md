# Course Overview

*Original Note: [[L01 - L01 — Course Overview and Basic Matrix Algebra]]*

### Topics
1. Core linear algebra ideas for data problems
2. Matrix factorizations
   - A = LU
     - L: lower triangular matrix
     - U: upper triangular matrix
   - A = QR
     - Q: matrix with orthonormal columns (orthogonal if square)
     - R: upper triangular matrix
     - QR is especially useful for least-squares problems
3. SVD and eigenvalues/eigenvectors
4. Connecting matrices to probability and statistics
5. Optimization methods (conjugate gradients and variants)
6. Mathematical core of deep learning

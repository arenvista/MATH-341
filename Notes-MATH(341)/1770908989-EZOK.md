# Patial Pivoting

> [!def] Partial Pivoting
> _"In practice always use $P$ to preform what is known as partial pivoting."_
> 
> We search column $k$ below the diagonal entry and swap the rows so tha: $x_{kk}$ is as large as possible.
> - Where $x_{kk}$ is the pivot (which must be as large as possible)
> - If done, we retain "numerical stability"; this minimizes the effect of rounding errors
> 
> 
> This can be visualized as coupling:
> $$
>     PA = LU
> $$ 
> 
> By solving $Ax=b$ consider $PAx=Pb$ is akin to $LUx=Pb$

# Singular Value Decomposition (SVD)

Let $A \in \mathbb{R}^{m \times n}$ be any rectangular matrix. The Singular Value Decomposition (SVD) of $A$ is factored as:

$$A = \underbrace{U}_{\text{Orthogonal}} \ \underbrace{\Sigma}_{\text{Diagonal}} \ \underbrace{V^T}_{\text{Orthogonal}}$$

Where:
* **$U$**: An $m \times m$ orthogonal matrix ($U^TU = I$). Its columns are called the **left singular vectors**.
* **$\Sigma$**: An $m \times n$ diagonal (or rectangular-diagonal) matrix containing non-negative entries $\sigma_i$ called **singular values**, sorted in descending order ($\sigma_1 \ge \sigma_2 \ge \dots \ge 0$).
* **$V$**: An $n \times n$ orthogonal matrix ($V^TV = I$). Its columns are called the **right singular vectors**.

---

# SVD as a Sum of Rank-One Matrices

Instead of matrix multiplication, $A$ can be expressed equivalently as a linear combination of rank-one outer products:

$$A = \sum_{j=1}^{r} \sigma_j u_j v_j^T$$

Here, $r = \text{rank}(A)$, $\sigma_j$ is the $j$-th singular value, and $u_j, v_j$ are the corresponding $j$-th left and right singular vectors.

### Partial Sums (Rank-$\nu$ Approximation)
We can truncate this sum to the first $\nu$ terms to create a partial sum $A_\nu$:

$$A_\nu = \sum_{j=1}^{\nu} \sigma_j u_j v_j^T$$

This truncated matrix $A_\nu$ captures the maximum possible information about $A$ using a rank of at most $\nu$.

---

# Fundamental Theorems of SVD

> [!note] Theorem: Rank from Singular Values
> The exact rank of matrix $A$, denoted as $r$, is strictly equal to the number of non-zero singular values.

> [!note] Theorem: Range and Nullspace
> The columns of $U$ and $V$ form orthonormal bases for the fundamental subspaces of $A$:
> * **Range (Column Space):** $\text{Range}(A) = \text{span} \{ u_1, \dots, u_r \}$
> * **Nullspace:** $\text{Null}(A) = \text{span} \{ v_{r+1}, \dots, v_n \}$

> [!important] Theorem: Best Low-Rank Approximation (Eckart–Young Theorem)
> For any rank constraint $0 \leq \nu \leq r$, the truncated SVD matrix $A_\nu$ is the best possible approximation of $A$ in the 2-norm (and Frobenius norm). 
> 
> $$\|A - A_\nu\|_2 = \inf_{\text{rank}(B)\leq\nu} \|A - B\|_2 = \sigma_{\nu+1}$$
>
> **In plain English:**
> * Among all possible matrices $B$ that have a rank of at most $\nu$, $A_\nu$ is the one mathematically closest to $A$.
> * The "error" or "loss of information" of this approximation is exactly equal to the next largest omitted singular value, $\sigma_{\nu+1}$.
> * If $A$ is full rank ($\nu = \min(m, n)$), then $\sigma_{\nu+1} = 0$, meaning the approximation is exact (zero error).

> [!tip] Corollary: Full Rank Stability
> Let $A \in \mathbb{R}^{m \times n}$ have full rank, with its smallest non-zero singular value being $\sigma_r > 0$. If you perturb $A$ to create a new matrix $B$ such that the error $\|A - B\|_2 < \sigma_r$, then $B$ is guaranteed to also have full rank. (Small changes don't destroy full rank).

### Numerical Rank
In computer arithmetic (like IEEE double-precision), true zeros are rare due to floating-point errors. The **numerical rank** of $A$ is considered to be $k$ if:
$$\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_k \geq \epsilon \gg \sigma_{k+1}$$
Where $\epsilon$ is a precision threshold (typically around $10^{-16}$). Values below this threshold are treated as computational noise.
*(Note: The largest singular value $\sigma_1 = \|A\|_2$)*

# SVD vs. Eigenvalue Decomposition (EVD)

## Eigenvalue Decomposition
If a square matrix $A \in \mathbb{R}^{n \times n}$ has $n$ linearly independent eigenvectors, it can be diagonalized as $A = X \Lambda X^{-1}$, where $X$ contains the eigenvectors and $\Lambda$ contains the eigenvalues. 

## Differences

| Feature | Singular Value Decomposition (SVD) | Eigenvalue Decomposition (EVD) |
| :--- | :--- | :--- |
| **Generality** | Applies to **all** matrices ($m \times n$). Uses two different bases ($U, V$). | Only applies to **square** matrices ($n \times n$) that are diagonalizable. Uses one basis ($X$). |
| **Orthogonality** | Always uses strictly **orthogonal** bases ($U^TU = I, V^TV = I$). | Eigenvectors are only orthogonal if $A$ is symmetric. Otherwise, $X$ is just non-singular. |
| **Existence** | Guaranteed to exist for every single matrix. | Only exists if algebraic multiplicity equals geometric multiplicity for all eigenvalues. |

## Theorem: The Relationship between SVD and EVD
The non-zero singular values of $A$ are the square roots of the non-zero eigenvalues of $A^TA$ (or $AA^T$).
*(Note: $A^TA$ and $AA^T$ share the exact same non-zero eigenvalues. In practice, compute whichever results in the smaller matrix).*

**Proof:**
Substitute $A = U \Sigma V^T$ into $A^TA$:
$$
\begin{align*}
A^TA &= (U \Sigma V^T)^T (U \Sigma V^T) \\
     &= V \Sigma^T U^T U \Sigma V^T \\
     &= V (\Sigma^T \Sigma) V^T
\end{align*}
$$
Because $V$ is orthogonal ($V^T = V^{-1}$), this equation is exactly the Eigenvalue Decomposition of $A^TA$. Therefore, the eigenvalues of $A^TA$ are the diagonal entries of $\Sigma^T \Sigma$, which are $\sigma_i^2$.

# Least Squares Solution via SVD

**The Problem:**
Given a matrix $A \in \mathbb{R}^{n \times m}$ and a vector $b \in \mathbb{R}^n$, we want to find $x \in \mathbb{R}^m$ that minimizes the Euclidean error $\|b - Ax\|_2$. Furthermore, if there are infinitely many solutions, we want the $x$ with the smallest magnitude ($\|x\|_2$).

### Mathematical Derivation
Let $r = \text{rank}(A)$ and $A = U \Sigma V^T$. 
Because multiplying by an orthogonal matrix does not change the 2-norm of a vector, we can multiply the error term by $U^T$:
$$\|b-Ax\|_2 = \|U^T(b-Ax)\|_2 = \|U^T b - \Sigma (V^T x)\|_2$$

Let's define new rotated variables:
* $c = U^T b = \begin{bmatrix} \hat{c} \\ d \end{bmatrix}$ (where $\hat{c}$ has length $r$)
* $y = V^T x = \begin{bmatrix} \hat{y} \\ z \end{bmatrix}$ (where $\hat{y}$ has length $r$)

Substitute these in:
$$c - \Sigma y = \begin{bmatrix} \hat{c} \\ d \end{bmatrix} - \begin{bmatrix} \hat{\Sigma} & 0 \\ 0 & 0 \end{bmatrix} \begin{bmatrix} \hat{y} \\ z \end{bmatrix} = \begin{bmatrix} \hat{c} - \hat{\Sigma}\hat{y} \\ d \end{bmatrix}$$

To minimize this norm, we look at the sum of squares:
$$\text{Error}^2 = \sum_{i=1}^r |\hat{c}_i - \sigma_i \hat{y}_i|^2 + \sum_{i=r+1}^{n} |d_i|^2$$
The $d_i$ terms cannot be changed. To minimize the error, we force the first summation to zero by setting:
$$\hat{y}_i = \frac{\hat{c}_i}{\sigma_i} \quad \text{for } i = 1, \dots, r$$
To ensure $x$ has the minimum possible norm, we set the free variables $z = 0$.

### Algorithm Summary
1.  Compute the SVD: $A = U \Sigma V^T$.
2.  Compute $c = U^T b$.
3.  For the first $r$ components, calculate $\hat{y}_i = c_i / \sigma_i$.
4.  For the remaining $m-r$ components, set $z_i = 0$.
5.  Construct $y = \begin{bmatrix} \hat{y} \\ z \end{bmatrix}$.
6.  Transform back to the original space: $x = Vy$.

---

# The Moore-Penrose Pseudoinverse

The steps above define the operation of the Moore-Penrose Pseudoinverse, denoted $A^\dagger \in \mathbb{R}^{m \times n}$.

Given $A = U \Sigma V^T$, the pseudoinverse is defined as:
$$A^{\dagger} = V \Sigma^{\dagger} U^{T}$$
Where $\Sigma^{\dagger}$ takes the reciprocal of all non-zero singular values and leaves the zeros alone:
$$\Sigma^{\dagger} = \begin{bmatrix} \hat{\Sigma}^{-1} & 0 \\ 0 & 0 \end{bmatrix}$$

In summation form:
$$A^{\dagger} = \sum_{i=1}^{r} \frac{1}{\sigma_i} v_i u_i^T$$

> [!note] Theorem: Minimum Norm Least Squares Solution
> Let $A \in \mathbb{R}^{n \times m}$ and $b \in \mathbb{R}^n$. The unique vector $x$ that minimizes $\|b - Ax\|_2$ and has the minimal norm $\|x\|_2$ is given directly by:
> $$x = A^{\dagger}b$$

**Proof:**
Using the SVD least-squares algorithm derived in Section 5, we established that the optimal solution is $x = Vy$, where $y = \Sigma^\dagger c$ and $c = U^Tb$.
Substituting these sequentially:
$$
\begin{align*}
x &= V y \\
  &= V (\Sigma^\dagger c) \\
  &= V \Sigma^\dagger (U^T b) \\
  &= (V \Sigma^\dagger U^T) b \\
  &= A^\dagger b
\end{align*}
$$
Thus, $A^\dagger b$ mathematically encapsulates the entire SVD least-squares process in one elegant matrix multiplication.

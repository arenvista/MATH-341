# Orthogonal Complements and Fundamental Subspaces

Let $A \in \mathbb{R}^{m \times n}$. We want to formally prove the relationship between the column space (Range) and the left null space. 

Suppose we take a vector $x$ that is in the orthogonal complement of the Range of $A$, denoted as $x \in R(A)^\perp$. By definition, this means $x$ is orthogonal to every vector in $R(A)$. 
Since any vector in $R(A)$ can be written as $Ay$ for some $y \in \mathbb{R}^n$, we have:

$$
\begin{align}
    \forall y \in \mathbb{R}^n, \quad 0 &= \langle x | Ay \rangle \\
    &= x^T (Ay) \\
    &= (x^T A) y \\
    &= (A^T x)^T y \\
    &= \langle A^T x | y \rangle
\end{align}
$$

For the inner product $\langle A^T x | y \rangle$ to be $0$ for *all* possible vectors $y \in \mathbb{R}^n$, the vector $A^T x$ must be the zero vector itself:
$$A^T x = 0 \implies x \in N(A^T)$$

Therefore, the orthogonal complement of the column space is exactly the left null space:
$$R(A)^\perp = N(A^T)$$

By applying the exact same logic (replacing $A$ with $A^T$), we get the relationship for the row space and the null space:
$$R(A^T)^\perp = N(A)$$

# Linear Transformations and Direct Sums

Multiplication by $A$ represents a linear transformation from $\mathbb{R}^n$ to $\mathbb{R}^m$:
$$x \in \mathbb{R}^n \xrightarrow{A} Ax \in \mathbb{R}^m$$
Where $\text{rank}(A) = r \leq \min(m,n)$.

### The Fundamental Theorem of Linear Algebra
Using the orthogonal complements proven above, we can partition our domain ($\mathbb{R}^n$) and codomain ($\mathbb{R}^m$) into orthogonal subspaces. 
*Recall: Dimension of $N(A)$ (Nullity) = Number of Columns - Rank.*

**In the Domain ($\mathbb{R}^n$):**
$$R(A^T) \perp N(A)$$
* $\text{dim}(R(A^T)) = r$
* $\text{dim}(N(A)) = n - r$
* Direct Sum: $\mathbb{R}^n = R(A^T) \oplus N(A)$

**In the Codomain ($\mathbb{R}^m$):**
$$R(A) \perp N(A^T)$$
* $\text{dim}(R(A)) = r$
* $\text{dim}(N(A^T)) = m - r$
* Direct Sum: $\mathbb{R}^m = R(A) \oplus N(A^T)$

# Orthonormal Bases and Fourier Expansion

*"The best basis is an orthonormal basis."*

> **Definition: Orthonormal Basis**
> A set of vectors $B = \{ u_1, u_2, \dots, u_n \}$ forms an orthonormal basis for an inner product space if every vector is orthogonal to all others, and every vector has a length (norm) of $1$.
> $$\langle u_i | u_j \rangle = u_i^T u_j = \delta_{ij}$$
> Where $\delta_{ij}$ is the Kronecker delta: $\delta_{ij} = 1$ if $i=j$, and $0$ if $i \neq j$.

### Generalized Fourier Expansion
Because the basis vectors are perfectly independent and scaled to $1$, any vector $x$ in this space can be easily decomposed into a linear combination of these basis vectors:
$$x = \langle u_1 | x \rangle u_1 + \langle u_2 | x \rangle u_2 + \dots + \langle u_n | x \rangle u_n$$

* **Fourier Coefficients:** The scalar value $\langle u_i | x \rangle$ is simply the projection length of $x$ onto the direction of $u_i$.

# Orthogonal Matrices

We can place our orthonormal basis vectors $u_1, \dots, u_n$ as the columns of a matrix $Q$:
$$Q = \begin{bmatrix} u_1 & u_2 & \dots & u_n \end{bmatrix}$$

Because the columns are orthonormal, multiplying $Q^T$ by $Q$ yields the Identity matrix:
$$
Q^T Q = 
\begin{bmatrix} u_1^T \\ u_2^T \\ \vdots \\ u_n^T \end{bmatrix}
\begin{bmatrix} u_1 & u_2 & \dots & u_n \end{bmatrix} = I
$$

> **Nomenclature Check:**
> * If $Q$ is rectangular: "It is a matrix with orthonormal columns." (Note: $Q^T Q = I$, but $Q Q^T \neq I$).
> * If $Q$ is square: "It is an orthogonal matrix." (Here, $Q^T = Q^{-1}$, so $Q^T Q = Q Q^T = I$).

### Preservation of Length
A key property of orthogonal matrices is that they preserve the size of a vector during transformation: $\|Qx\| = \|x\|$.

**Proof:**
$$\|Qx\|^2 = \langle Qx | Qx \rangle = (Qx)^T(Qx) = x^T Q^T Q x$$
Since $Q^T Q = I$:
$$x^T I x = x^T x = \|x\|^2$$
*Examples of Orthogonal Matrices: Rotations, Reflections, Permutation matrices.*

# Elementary Orthogonal Projectors

An orthogonal projector $P_u$ is a matrix that takes any vector $x$ and flattens (projects) it onto the subspace spanned by vector $u$.

If $u$ is a unit vector ($\|u\| = 1$), the projector is formed using the outer product:
$$P_u = u u^T$$

If $u$ is *not* a unit vector ($\|u\| \neq 1$), we must normalize it:
$$P_u = \frac{u u^T}{u^T u}$$

### Action of the Projector
Let's see what happens when we apply $P_u$ to a vector $x$ (assuming $u$ is a unit vector):
$$P_u x = (u u^T) x$$
Because matrix multiplication is associative, we can group $u^T x$ (which is just the inner product scalar $\langle u | x \rangle$):
$$u (u^T x) = u \langle u | x \rangle = \langle u | x \rangle u$$
This perfectly matches our Fourier expansion logic: it results in a vector pointing in the direction of $u$, scaled by the projection length of $x$ onto $u$.
